What I heard

A recurring required_tool_missing failure stops builds because the installed Codex adapter explicitly refuses isolated review. Fix that prerequisite before continuing Agent Advocate, and have Agent Advocate detect such mismatches before work starts.

Why this shape

The source audit found three connected gaps: unconditional adapter refusal, helpers absent from installed packages, and a six-at-once dispatch requirement on a host with fewer agent slots. Existing Phase CD owns this repair; a second engine in Agent Advocate would duplicate ownership.

Six independent lenses remain required. Each is a new direct child with no inherited conversation and no sibling findings. Capacity-limited batches change scheduling; they do not remove reviews or allow the producer to grade itself.
