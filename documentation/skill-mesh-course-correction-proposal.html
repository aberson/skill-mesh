The corrected delay diagnosis

Abraham did run the thin experiment. The plan records a measured reinstall overwriting customized bytes with exit 0 and no backup. The earlier critique overstated the evidence.
Observe→Reproduce + measure→Classify→Sketch smallest options→Rebaseline if architecture changes→Approve + sync plan/issue→Implement

What actually went wrong

The measured safety defect expanded into installer + migrator + write-ahead authority/recovery + locking work while the plan was still marked unsafe and its declared files were narrower. The four-file WIP reached +1,843/-277.

What was not wrong

Wanting multiple lenses, deterministic tests, Claude/GPT resilience, and a future cheaper model lane was rational. The missing discipline was to expose each addition's unique proof, matrix cost, and defer/relax option.

Host/model correction: the shipped second host layer is GitHub Copilot-specific, not native Codex. A host adapter (Claude Code/Copilot/Codex) and a model family (Claude/GPT) are separate axes. Codex needs an explicit audit and retarget, while cross-family execution needs its own seam.

Two experiments, then an operator halt

A · package lifecycle

Use a unique probe, not an existing skill

Package two uniquely named probe skills plus a shared reference and helper. Install, resolve source, update, disable, uninstall, and test consumer-byte authority in isolated Claude Code and Codex profiles. This avoids a shadowed plan-redline false pass.

B · cross-family execution

Distribution does not choose the reviewer seam

Audit Claude, Copilot-specific, native Codex, and provider-router layers. Compare manual receipted handoff, a bounded external-review dispatcher, and deferred seamless automation on an immutable seeded diff.

No self-authorizing spike. PASS/PARTIAL/FAIL/AMBIGUOUS results produce recommendations. Abraham chooses package ownership, cross-family execution, and Step 4 disposition before implementation resumes.

Lifecycle both pass

Recommend native lifecycle, then compare one-time manual cutover/retirement with a bounded legacy utility. Do not presume a permanent migrator.

Lifecycle partial/fail

Recommend the smallest host-specific compatibility option or separately re-charter the installer.

Dispatcher passes

Recommend retaining only the bounded cross-family review seam, with explicit receipt/fallback policy.

Manual only / ambiguous

Surface the asymmetry or missing premise; do not turn adapter labels into execution proof.
