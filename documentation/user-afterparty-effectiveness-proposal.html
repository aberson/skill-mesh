These are bounded September observations; the original memory baseline was reconstructed. They do not establish prompt-token, cost or speed savings.

Use the existing core, provider adapters, report area and installer. No new runtime, dashboard, queue, cache or child-skill engine is needed.

What the acceptance must catch

  • A completed scan must remain distinguishable from applied cleanup, with unknown counts never invented as zero.
  • Old, interrupted, conflicting and skipped-item findings must remain visible with their actual evidence strength.
  • Dry-run must leave task outputs untouched; live worktrees must receive no recursive size walk.
  • An installed older profile, unavailable required observation, failed full test gate or ownership conflict cannot be reported as acceptance.
