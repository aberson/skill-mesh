Why this shape

Shared authorship, native execution, immutable releases.

“Shared core” means one file is authored—not that live hosts chase a mutable checkout. That keeps daily maintenance simple without making nested repos, worktrees, Windows links, or cloud sandboxes fragile.

Not in this cutover

Cut on purpose.

Invocation and provider cuts

  • GitHub Copilot support as an active endpoint
  • Generic model/provider router
  • Automatic provider or fallback-model selection
  • New providers, local models, or model-equivalence claims

Product-scope cuts

  • Wholesale behavior redesign during migration
  • New utility product features beyond documented interfaces
  • Observatory routing, mutation, or runtime dependency
  • Forcing three Claude-native skills into false portability
