The earlier 9–17 active-workday / 4–6-week chain is withdrawn. These projects deliver independently; estimates are planning judgments, not measured throughput or a calendar commitment.

| Project | Active effort | Dependency / gate | Delivered value |
|---|---:|---|---|
| 1. Reliable resume | Existing M1; no new estimate | Existing 126 → 127 → 128 → 129 and accepted continuation | Intended checkpoint resumes correctly |

| 4. Python tooling | **0.5–1 workday**, optional | Independent development-only scope and gates | Locked invocation of existing scripts |

| 5b. Observatory summary | **0.5–1 workday**, optional | Useful saved artifact and applicable checks | Existing reader displays useful results |

First new value is Project 2, not completion of every row. Its estimate excludes M1, trial qualification/adapters, hook changes and runtime packaging. AP is not a technical dependency; the proposed queue still preserves existing commitments.

Do not add rows into a promised total: some are optional, Project 1 is existing work and Project 3 has an unestimated capability branch. Active effort excludes slow gates, review corrections and waiting for attended acceptance. [Historical full Skill Mesh gates](../phase-75-baseline.md) took roughly 2.5–3.5 hours; this revision made no timing measurement.

Proof replaces quotas:

- Capture: unchanged-HEAD cycle, retry, duplicate/codified lesson, unsupported evidence, correction and dry-run preservation.
- Trial: one real cycle plus rejection/unavailable behavior; no mandatory winner.
- Resume: existing M1 cases; verify residual hook behavior if that path changes.
- Withdraw the five-session minimum, five-day soak, ten-example quota and blanket 24-execution matrix.

Failed route qualification leaves Project 2 useful and reports trials unavailable. A timebox limits spending; it cannot turn missing capability into a pass.
