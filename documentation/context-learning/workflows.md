## Example: wrong working directory

1. The assistant verifies a command failed because it ran in coding-root instead of the intended project, then corrects the directory.
2. A dedicated prose admission and explicit helper produce a durable observation receipt. Strict-format output remains untouched.
3. Harvest processes the observation despite no new commit, checking all five lesson stores.
4. If a rule already covers it, address why the invocation missed that rule instead of duplicating it.
5. Once Project 3 qualifies an evaluator, a non-dry-run handoff automatically trials the canonical candidate in isolation.
6. The operator reviews the exact diff, independent results and limitations before promotion.

Project 2 delivers through step 4; it does not wait for the evaluator.

## Example: corrected next action

A next action changes from “run acceptance” to “fix the prerequisite.” First prove M1 saves and explicitly resumes that intended checkpoint under the right plan/session identity. Add section history only if a specific correction remains unrecoverable after correct checkpoint selection.

## Operator experience

The first slice reports captured, already codified, needs evidence, or candidate prepared. Later trials add ready for review, no improvement, or trial unavailable. These are explanatory phrases, not replacements for locked scorer verdicts.

No automatic transcript coverage, global mistake-rate reduction or cross-host runtime parity is claimed.
